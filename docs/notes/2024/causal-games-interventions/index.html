01. 书目与阅读版本

书目与版本。 Manuj Mishra、James Fox、Michael Wooldridge，Characterising Interventions in Causal Games，UAI 2024（第 40 届），PMLR 244:2560–2572，官方 proceedings。章节与定理核读arXiv:2406.09318 全文；正式版与预印本不能无条件视作逐字相同。

02. 聚焦问题与文章结构

普通 do() 只说改了哪个变量，却未说明代理何时知道、是否有机会重新选策略。这种时序会改变博弈均衡和干预结果。§1 引言；§2 因果博弈背景；§3 四类原子干预与复合查询；§4 因果机制设计；§5 承诺博弈；§6 结论；附录给证明与承诺计算。

03. 形式化贡献与证据

因果博弈由机会、决策、效用变量和代理理性关系组成；理性关系可取最优反应/纳什均衡，不预设唯一均衡（§2）。§3.1 提出四种原语：替换对象层条件分布、改变机制/决策规则、增加变量、删除变量；定理 1 的“可靠且完备”指干预表达语言，不是从观察数据识别。§3.2 让每个代理只看见干预子集，依知情时序分阶段锁定或重算策略；定理 2 与算法 1 给查询分解。§4 用依赖路径和最小 hitting set 表述机制设计，§5 用小型承诺博弈展示不同披露/承诺时点可改变收益。本文主要是定理与教学例子，没有大规模市场实验。

04. 双读审稿结论

两位阅读者强调：均衡/最优反应假设很强，LLM 与散户未必依此行动；多均衡的选择和大规模求解也未解决。原文 §3.2/§6 说明一般计算困难。即使四原语完备，也不意味着一个现实监管干预的反事实由历史价格数据可识别。小型承诺收益例子不能直接外推到连续订单簿。

05. 接到 Meta Dev

每个冲击实验写一个干预标签：改的是消息/交易规则/代理策略机制中的哪一层，什么时候实施，谁在何时知情，谁能重新优化。预公告交易税与交易中突然征税应视为不同处理；否则“相同政策”在不同模拟器里可能根本不是同一反事实。

证据定位：UAI 正式页；原文 §2–6、定理 1–2、算法 1。
