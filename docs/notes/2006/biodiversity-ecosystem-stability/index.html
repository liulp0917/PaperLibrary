02. 聚焦问题与文章结构

操纵植物物种数，十年后群落年度生物量是否更稳定？物种自身与群落总体是否可能方向相反？本文是 Nature Letter，无通常的编号 IMRaD 章节：主文 p629–631 依次给假设/稳定度定义、十年与短时间窗结果、根量及功能群检验、协方差/统计平均/超产机制；p631 的 Methods 含实验设计、取样工作量、去趋势和其他分析，p632 为参考文献。

03. 设计、指标和结果

Cedar Creek 的 168 个 9×9m 草地小区被随机指定播种 1、2、4、8 或 16 种多年生植物，组成从 18 种中抽选；五个木本单种小区因维护制度与木本存活不对称而被排除，不能把 168 当成全部回归样本。1994/95 年播种，1996–2005 年每年测地上生物量，统一除草和春季火烧。稳定度 S=跨年平均生物量/跨年标准差；十年主指标先对每块地的时间趋势去除再求稳定度，短窗口则不去趋势。p629 图 1：最高多样性处理在去趋势后的稳定度平均比单种高约 70%；物种数效应 F(1,161)=44.9, p<0.0001，两段五年和五个两年窗口方向也为正。p630：单物种自身稳定度在高多样性群落反而更低。p631：总协方差随物种数没有显著趋势 F(1,161)=0.83,p=.36，不是说协方差数值等于零；物种生物量方差对均值的幂律指数约 1.60 支持统计平均效应；16 种处理的总生物量在 2001–05 年平均比单种高约 180%，不是稳定性高 180%。根量、豆科组成等事后回归不能自动当作随机机制效应。

04. 双读审稿结论

作者的因果识别限于这类管理制度、地点和相对生物量波动指标；μ/σ 混合均值与波动，不等于尾部危机抵抗力。必须公平指出：原文图 3 还给出在相同均值下，高多样性处理的时间标准差较低，所以不能说结果“纯由均值上升解释”。两位阅读者一致强调：生物物种不是交易策略，金融市场的共同资产、共享模型先验、杠杆与价格冲击可让“多样性—韧性”关系反转。未检测到协方差机制，不应宣传“异步波动一定是主要机制”；两个观测点的两年稳定度尤其噪声较大。
